Project Overview

My Library is a desktop application designed to manage a personal collection of media, specifically books and films. It utilizes a reliable three-tier architecture: a Tkinter-based desktop Frontend, a Python Flask Backend for API services, and a simple JSON database for persistence.

Technology Stack:

  • Frontend: Python 3 (Tkinter/ttk) & Requests library
  • Backend:Python 3 (Flask) & Secure file handling
  • Database: Local JSON file (`pageturn_data.json`)

Key Features

Inventory (CRUD)

Seamlessly add, view, update, and delete media items (books, films, magazines). Manage your collection with ease.

Smart Search & Filter

Quickly find media items by title or creator using the integrated search bar, with instant results.

Run Instructions

The system operates as two separate processes communicating via a local API.

Step 1: Setup Environment

# Install required Python packages
pip install Flask requests

Step 2: Start Backend Server (Terminal 1)

python backend.py

Step 3: Launch Frontend GUI (Terminal 2)

python frontend.py

⚠️ Ensure the backend server is fully running before launching the frontend GUI.
