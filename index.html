Run Instructions

The system operates in two separate processes using an API.

Step 1: Install Packages

pip install Flask requests

Step 2: Run Backend

python backend.py

Step 3: Run Frontend

python frontend.py

⚠ Ensure backend is running before starting the frontend GUI.
