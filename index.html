Project Overview

My Library is a desktop application designed to manage a personal collection of media...

Technology Stack:

  • Frontend: Python Tkinter
  • Backend: Python Flask
  • Database: JSON file (pageturn_data.json)

Key Features

Inventory (CRUD)

Add, view, update, and delete items.

Smart Search

Instant search for books and films.

Run Instructions

The system operates in two separate processes using an API.

Step 1: Install Packages

pip install Flask requests

Step 2: Run Backend

python backend.py

Step 3: Run Frontend

python frontend.py

⚠ Ensure backend is running before starting the frontend GUI.
