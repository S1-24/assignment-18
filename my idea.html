🎮 Superman vs Batman – 2D Multiplayer Game

Superman vs Batman is a fast-paced 2D multiplayer game developed by me as a personal project. The game allows two players to battle each other using unique character powers and weapons.

🦸 Superman

Superman uses a powerful shooter weapon that fires energy projectiles. His attacks are fast, long-ranged, and deadly in battle.

🦇 Batman

Batman uses his signature Bat Ring weapon. It acts like a boomerang, damaging enemies and returning back.

✨ Game Features

  • Real-time local multiplayer mode
  • Smooth 2D animations
  • Unique character weapons
  • Keyboard controls for both players
