🎮 Superman vs Batman – 2D Multiplayer Game

Superman vs Batman is a fast-paced 2D multiplayer game where two players use unique characters and weapons in real-time combat.

📸 Game Preview

🦸 Superman

Uses a shooter weapon that fires powerful energy blasts at long range.

🦇 Batman

Uses Bat Rings that damage enemies and return like a boomerang.

✨ Game Features

  • Real-time local multiplayer
  • Smooth 2D animations
  • Unique characters & abilities
  • Fast keyboard controls
